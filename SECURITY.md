# Security and Privacy

Never commit access tokens, private observing proposals, submission links,
correspondence, home addresses, or personal email addresses. Archive downloads
and external executables are opt-in and outside the supported offline audit.

If a credential leak is found, contact the repository owner privately via the
hosting platform; do not paste the credential into an issue. Rotate the
credential before rewriting history. Raw-data scripts under `research/` are
historical references and must be reviewed before execution.
