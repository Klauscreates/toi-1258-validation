# Historical Manuscript Source

These are historical manuscript sources and associated figures, not a newly
revised or accepted paper. Their assertions may conflict with the current
[scientific status](../docs/SCIENCE.md), which takes precedence.

Personal email addresses and machine paths were removed. See the
[source inventory](../research/SOURCE_INVENTORY.json) for original/export hashes.
LaTeX and bibliography sources are retained, but temporary compiler products and
PDFs with potentially embedded personal metadata are excluded. External LaTeX
packages and figure paths may need configuration; compilation was not verified.

Private correspondence, cover letters and portal fields are excluded.
